# 在线考试系统 - FrontEnd
### 一个伟大的项目
- [BackEnd](https://github.com/Simon-xxx-Ben/SoftwareTestingProjectBackend)
### 功能概述
- 考试列表（展示可参加的考试）
- 参加考试（在线答题和提交试卷）
-	计时功能（考试倒计时和提醒）
-	自动评分（系统自动计算分数）
-	成绩查看（查询历史考试成绩）
-	错题本（自动记录错题并解析）
-	模拟考试功能（提供模拟试题和练习模式）
- 能力画像生成：知识点掌握度分析 + 错题关联推荐 + 能力成长曲线
- 自适应练题：根据答题表现动态调整后续题目难度
